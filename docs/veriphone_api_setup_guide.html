Veriphone.io Carrier Lookup

Veriphone.io API Setup Guide

Configure Veriphone.io for live phone-number carrier, line-type, country, and formatting metadata checks. For a normal dashboard demo, paste the key into the Phone Number tab provider card. Store persistent keys outside source code.

Setup Steps

  1. Create or sign in to your Veriphone.io account.
  2. Open https://veriphone.io/app and retrieve an API key.
  3. For a quick demo, paste the key into the Veriphone.io provider card inside the Phone Number tab and press Enter.
  4. For persistent setup, add the key to your local .env file, environment variable, or Streamlit secrets.
  5. Restart Streamlit after changing environment variables or secrets.
VERIPHONE_API_KEY=your_veriphone_key_here

Open Veriphone.io API documentation

Never commit .env, .streamlit/secrets.toml, or real API keys to GitHub.

Lookup Behavior

  1. The app normalizes Malaysian phone numbers into one internal international format.
  2. The app calls Veriphone.io only when the provider is enabled and a Veriphone.io API key is configured.
  3. The dashboard uses Veriphone.io metadata as neutral carrier/line context, not as scam reputation or legal proof.
  4. If the key is rejected, credits are exhausted, or the provider times out, the sidebar and diagnostics show the provider status.
  5. If no provider returns usable evidence, the phone investigation returns Unknown, not Safe.

Free-tier note: Veriphone.io currently lists 1,000 free credits per month. Standard validation uses 1 credit, while current carrier lookup uses 10 credits. Confirm the latest limits before a live demo.
